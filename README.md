## 📖 Tentang

**MISTER-MD** adalah script bot WhatsApp Multi-Device berbasis Node.js dan Baileys. Script ini dirancang agar mudah dipasang, stabil dijalankan, dan nyaman dikembangkan sesuai kebutuhan.

## ✨ Fitur Utama

- 🛡️ **Moderasi Grup** — Anti Link, Anti Toxic, Anti Tag Status, dan Anti Channel
- 👥 **Auto Join Grup** & **Auto Follow Channel**
- 🤖 **Jadibot** — jadikan nomor lain sebagai bot
- 🖥️ **Menu Pterodactyl** — kelola panel langsung dari WhatsApp
- 💳 **Menu Payment**
- 🎨 **Sticker, Image, dan Downloader**
- 🧠 **Menu AI**
- 🔐 **Proteksi password script** saat login

> Daftar lengkap fitur dapat dilihat lewat perintah menu di dalam bot.

## 🚀 Cara Instalasi dan MMenjalanka

### Install dependensi

```bash
npm install
```

### Atur konfigurasi

Buka file `settings.js`, lalu isi data berikut sesuai milikmu:

- Nomor owner
- Nama bot dan nama owner
- Link grup dan link channel
- Pengaturan lain yang tersedia di file tersebut

### Jalankan bot

```bash
npm start
```

### Login ke WhatsApp

1. Masukkan **password script** saat diminta di terminal.
2. Masukkan **nomor WhatsApp** dengan format `62xxxxxxxxxx`.
3. Salin **kode pairing** yang muncul.
4. Buka WhatsApp, pilih **Perangkat tertaut**, lalu **Tautkan dengan nomor telepon**, dan masukkan kodenya.

Setelah terhubung, bot akan mengirim pesan **Bot Succes Connect** ke nomormu.

## 🛠️ Troubleshooting

| Masalah | Solusi |
| ------- | ------ |
| `Cannot find module` | Jalankan ulang `npm install` |
| Sticker atau video tidak jalan | Pastikan FFmpeg sudah terpasang |
| Bot tidak bisa hapus atau kick di grup | Jadikan bot **admin grup** |
| Gagal login | Hapus folder `session`, lalu jalankan ulang `npm start` |
